name: lessons
description: Draw the lessons of this session (corrections, mistakes, what worked) as proposed memory notes; run by the person.
disable-model-invocation: true
---

Look back at this session and propose what is worth remembering. A lesson is worth a note only if it would change how the next session works.

1. **Find the moments that taught something:** where the person corrected you (quote their words), where a command or an assumption failed and why, where something took several tries, where an approach worked well and the person confirmed it.
2. **Keep only what repeats or will repeat.** A one-off fact about today's task is not a lesson. A rule the person stated, or a mistake that could happen again, is.
3. **Write each as a proposal:** the rule in one sentence, why (the moment it came from, with the person's words), and how to apply it. Check the memory for a note that already covers it: then propose an update to that note, not a new one.
4. Show the proposals; write only those the person approves, as their memory's own format asks.
