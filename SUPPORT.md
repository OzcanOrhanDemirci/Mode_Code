# Getting help

1. **Run `mode-code doctor`.** It checks every feature and says, for each problem, how to fix it. `mode-code doctor --fix` repairs what it safely can.
   - **The installation went wrong?** Run the [install line](README.md#install) again: it repairs an installation. A message it printed tells you the step that failed.
2. **Read the docs:** [README](README.md), [command line](docs/cli.md), [keywords](docs/keywords.md), [modes](docs/modes.md), [safety belt](docs/safety-belt.md), [memory](docs/memory.md), [architecture](docs/architecture.md).
3. **Ask a question** in the repository's Discussions.
4. **Found a bug?** Open an issue with the bug report form. `mode-code doctor --json` output helps; it contains no personal data, but look it over before you paste it.
5. **Security problems** go to [SECURITY.md](SECURITY.md), never to a public issue.

This is a personal open-source project: answers come as time allows, usually within a few days.
