# Command line

`mode-code` with no command opens the control center in a terminal; piped or in CI it prints the status instead. Every command accepts `--json` and `--no-color` (also honoured: `NO_COLOR`, `FORCE_COLOR`). The interface language follows the settings file, then `MODE_CODE_LANG`, `LC_ALL`, `LC_MESSAGES`, `LANG`, then the system locale.

## JSON output

`--json` prints one JSON document. Its `schema` field names the command and a version, for example `mode-code.status/1`. Within a version fields are only added, never renamed or removed, so scripts keep working. `version` is the tool's version.

## The settings file

`~/.mode-code/config.json` (or `$MODE_CODE_HOME/config.json`). Every key is optional; a wrong value falls back to its default for that key only, and `doctor` lists what was wrong. The safety belt's locked rules cannot be weakened from this file.

```json
{
  "language": "auto",
  "view": "recommended",
  "modules": {
    "keywords": true,
    "footer": true,
    "quota": true,
    "secrets": true,
    "status": true,
    "notifications": true,
    "quietWork": true,
    "modes": true,
    "mascot": true
  },
  "belt": {
    "disabled": [],
    "verdicts": { "git.force-push": "deny" },
    "protectedBranches": ["main", "master", "release/*"],
    "prOnlyRepos": ["github.com/me/app"],
    "singleBranchRepos": [],
    "packs": { "dockerVolumes": false }
  },
  "memory": { "dirs": ["~/notes"] },
  "footer": { "mode": "draw", "showFiveFrom": 70, "showWeekFrom": 85 },
  "quota": { "fiveHourWrapUp": 95, "fiveHourStop": 99, "defaultWeeklyTarget": 99, "defaultWeeklyWrapUp": 97, "staleMinutes": 360, "autoResume": true },
  "keywords": { "extra": { "en": { "continue": ["go on"] } } },
  "projects": [{ "id": "my-app", "names": ["app"], "path": "~/dev/my-app", "verify": ["npm run check"] }],
  "modes": { "workDir": null },
  "autonomy": { "enabled": false, "maxHours": 12, "stallMinutes": 90, "reviewModel": null },
  "bypass": { "enabled": false, "maxHours": 2 },
  "update": { "check": false },
  "packs": { "autoUse": true, "items": { "store": "me" } },
  "skills": { "items": { "tdd": "on", "teach": "me" } },
  "accessibility": { "plain": false, "highContrast": false, "reduceMotion": false }
}
```

## Environment variables

| Variable                  | Effect                                                                        |
| ------------------------- | ----------------------------------------------------------------------------- |
| `MODE_CODE_HOME`          | The data folder (default `~/.mode-code`)                                      |
| `MODE_CODE_LANG`          | Interface language, `en` or `tr`                                              |
| `CLAUDE_CONFIG_DIR`       | Where Claude Code's configuration is (read the same way Claude Code reads it) |
| `NO_COLOR`, `FORCE_COLOR` | Colors in command output                                                      |

The one-line installers (`install.sh`, `install.ps1`) read these too:

| Variable                | Effect                                                                                                                                          |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `MODE_CODE_INSTALL_DIR` | Where the program goes (default `~/.local/share/mode-code`; Windows `%LOCALAPPDATA%\mode-code`)                                                 |
| `MODE_CODE_BIN_DIR`     | Where the `mode-code` command goes (default `~/.local/bin`; Windows `%USERPROFILE%\.local\bin`)                                                 |
| `MODE_CODE_RELEASE_URL` | Where a release's files are, checked against its `SHA256SUMS` (default: the GitHub release); `mode-code update` and its daily check read it too |
| `MODE_CODE_PACKAGE`     | A package to install instead of a release's: a `.tgz` file or its address (no checksum)                                                         |
| `MODE_CODE_NODE_MIRROR` | Where Node.js is downloaded from, when it is (default `https://nodejs.org/dist`)                                                                |
| `MODE_CODE_LANG`        | The language of their messages, `en` or `tr`                                                                                                    |
