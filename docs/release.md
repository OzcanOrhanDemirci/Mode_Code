# Releasing

How Mode_Code goes from this repository to a package anyone can install, and what was checked before it does. Until the first release this page is also the plan: what is ready, and what waits for a person's decision.

## Plan and status

Written 2026-10-13, kept as a checklist. Everything here can be done and tested before the decisions; nothing here makes the repository public, publishes a package or picks the name.

- [ ] This plan.
- [ ] **Audit before going public.** The tracked files, every commit reachable from any branch, and the package's own files, scanned for secrets (gitleaks and the tool's own scanner), the author's paths, machine names and addresses, large files and license lines. What is found in the files is fixed; what is found only in history is reported, since rewriting history is the person's decision. What ships is kept clean by a test.
- [ ] **The package as npm installs it (L12).** `npm pack`, the file list held to an exact expectation, then the tarball installed into an empty prefix with no network and the whole command-line process suite run against the installed program, through npm's own launcher on Windows.
- [ ] **A rename that is rehearsed, not hoped for.** The name is temporary. `scripts/rename.ts` renames every spelling of it in one pass and records the old one; the installer recognises an installation under an earlier name and moves it: data and settings kept, hooks swapped in one write, the old plugin removed, the old folder removed only after the new installation tested itself. A rehearsal installs today's build, renames a copy of the repository, builds it and installs it over the old one.
- [ ] **The release pipeline.** A workflow that runs on a version tag: the tag, `package.json` and the changelog must agree, every check passes, the package is built once, published with provenance and attached to a GitHub release whose notes are the changelog's section, with its SHA-256.
- [ ] **Going public, prepared.** One script that shows, then applies, the repository settings a public project needs (description, topics, discussions, squash merges, secret scanning with push protection, private vulnerability reporting, Dependabot alerts, a rule set for `main`), run by the person from their own terminal.
- [ ] **The README's pictures.** The control center drawn by the program itself from sample data into SVG files, a short animation of moving through it, regenerated by one script.
- [ ] Testing guide, README, changelog; measured.

Decided on 2026-10-14: the name is Mode_Code (command, package and data folder `mode-code`). Waiting for a person: the first version number, making the repository public, the npm account and the first publish.
